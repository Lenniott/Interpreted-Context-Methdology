# Portfolio Case Studies Workspace

Take a project you worked on through capture, angle, draft, and polish to produce a portfolio case study about design, problem solving, or collaboration.

## Task Routing

| Task Type | Go To | Description |
|-----------|-------|-------------|
| Capture a project | `stages/01-capture/CONTEXT.md` | Draws out the raw facts of a project into a dossier |
| Choose the angle | `stages/02-angle/CONTEXT.md` | Picks the story, thesis, and outline from the dossier |
| Write the draft | `stages/03-draft/CONTEXT.md` | Turns the brief into a full case study draft |
| Polish the draft | `stages/04-polish/CONTEXT.md` | Edits for voice, evidence, and clarity |

{{?PUBLISH_STAGE}}

### Publish Stage

The publish stage (05-publish) formats the polished case study for a specific platform (portfolio site, Notion, PDF). If you only need the written case study in markdown, this stage can be removed during onboarding.

{{/PUBLISH_STAGE}}
