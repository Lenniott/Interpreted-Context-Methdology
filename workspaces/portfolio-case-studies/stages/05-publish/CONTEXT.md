# Stage 05: Publish

Format the polished case study for a specific platform so it is ready to post.

## Inputs

| Source | File/Location | Section/Scope | Why |
|--------|--------------|---------------|-----|
| Previous stage | `../04-polish/output/[project-slug]-case-study.md` | Full file | The finished case study to format |
| Reference | `references/format-guide.md` | Section matching {{PUBLISH_PLATFORM}} | The formatting rules for the target platform |

## Process

1. Read the polished case study and the format guide section for {{PUBLISH_PLATFORM}}.
2. Apply the platform's structure: heading levels, summary or hero block, image placement, and any metadata the platform expects.
3. Convert the bracketed visual notes into the platform's image syntax, or list them as an asset checklist if the images do not yet exist.
4. Produce the publish-ready file in the platform's format.
5. Save to output/.

## Outputs

| Artifact | Location | Format |
|----------|----------|--------|
| Publish-ready case study | `output/[project-slug]-publish.md` | The case study formatted for {{PUBLISH_PLATFORM}}, plus an asset checklist for any pending visuals |
