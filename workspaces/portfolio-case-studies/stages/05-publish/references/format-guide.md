## Portfolio Site (Markdown or HTML)

- Open with a hero block: title, one-line summary, your role, and the timeframe.
- Use H2 for each anatomy section.
- Place images full-width between sections, each with a one-line caption.
- End with a short credits or role line.

## Notion

- Use a callout block for the summary and role.
- Toggle lists can hold supporting detail so the main read stays tight.
- Embed images at full width; captions go in the line below as small text.

## PDF or Slides

- One section per page or slide. Lead each with the section's headline sentence.
- Keep body text short; let visuals carry weight.
- Include a cover with title, role, and date, and a closing slide with the reflection.

## Asset Checklist

For every bracketed visual note in the case study, list the image needed, whether it exists, and where it goes. Hand this list to the user so missing visuals can be produced before publishing.
