# Stage 02: Angle

Choose the story this case study tells and map it onto the case study structure as an outline.

## Inputs

| Source | File/Location | Section/Scope | Why |
|--------|--------------|---------------|-----|
| Previous stage | `../01-capture/output/[project-slug]-dossier.md` | Full file | The raw material to shape |
| Reference | `references/angle-patterns.md` | Full file | Common framings and how to choose one |
| Shared | `../../shared/value-framework.md` | Full file | The value types to tag and lock |
| Shared | `../../shared/impact-evidence.md` | "The Evidence Types" | The evidence the outline must give room to |
| Shared | `../../shared/case-study-anatomy.md` | Full file | The outcome-first structure to outline against |
| Author vault | `../../author-vault/identity.md` | "Audience" and "Positioning" | Who the angle must land for |

## Process

1. Read the dossier and identify the central tension -- the one problem this case study is really about -- and the single strongest outcome to lead with.
2. Propose 2-3 distinct angles, each as a single sentence thesis. For each, tag which value types it naturally hits and which reader it serves best. Tailor emphasis to the dossier's intended use.
3. **[Checkpoint 1]** -- Present the angles. The human picks one to pursue, modify, or combine.
4. For the chosen angle, lock the 2-3 value types this case study will deliver (see value framework) and the lead outcome. Write the one-line thesis.
5. Build the outline against the outcome-first anatomy: headline outcome, then problem, then key decisions (including a rejected path), then evidence, then reflection. Under each, note the points and the evidence that supports them.
6. **[Checkpoint 2]** -- Present the thesis, locked value types, lead outcome, and outline. The human confirms before drafting.
7. Run the audit checks below. If any fail, revise before saving.
8. Save the narrative brief to output/.

## Checkpoints

| After Step | Agent Presents | Human Decides |
|------------|---------------|---------------|
| 2 | 2-3 angle theses, each one sentence with value tags and target reader | Which angle to pursue, modify, or combine |
| 5 | Thesis, locked value types, lead outcome, and section-by-section outline | Confirm the direction before drafting begins |

## Audit

| Check | Pass Condition |
|-------|---------------|
| Single thesis | The case study has one clear thesis, not a list of themes |
| Outcome leads | The outline opens with the single strongest outcome, before the process |
| Value locked | 2-3 value types are chosen and each has room in the outline |
| Structure coverage | Every anatomy section has at least one point mapped to it |
| Rejected path planned | The key-decisions section includes at least one rejected path |
| Evidence mapped | Each outline point names the dossier evidence that supports it |
| Role in frame | The angle keeps the user's specific contribution visible |

## Outputs

| Artifact | Location | Format |
|----------|----------|--------|
| Narrative brief | `output/[project-slug]-brief.md` | Thesis, lead outcome, locked value types, target reader, and an outcome-first outline with evidence mapped |

The brief in `output/` is the human edit surface. Adjust the thesis, swap value types, reorder the outline. Stage 03 reads whatever is in that file.
